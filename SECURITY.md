# Security policy

## Report a security concern privately

For a suspected security vulnerability in Starbase 430's website, source, or
build tools, use GitHub's [Report a vulnerability form](https://github.com/sam-mcclanahan/starbase430-site/security/advisories/new).
Reports submitted there are private to the advisory's participants and authorized
repository maintainers. Please keep vulnerability details out of public issues
and pull requests while we assess the report.

Include the affected URL or file, the commit or version if known, steps to
reproduce, and the potential impact. A minimal proof of concept is helpful.
Do not include credentials, private writing, or other people's personal data.

## Report an ordinary bug

For broken links, layout problems, accessibility issues, or other ordinary bugs,
[open an issue](https://github.com/sam-mcclanahan/starbase430-site/issues) with
the affected URL, browser details, and steps to reproduce. If the issue includes
sensitive security details, use the private reporting form instead.

## Reviewing fixes

Dependency alerts and private reports are reviewed by the maintainers. Fixes go
through the repository's privacy checks, tests, and protected-branch process.
Website deployment remains a separately approved manual action.
