# Project goals

- A lightweight, portable independent-web workshop for Sam and Brea’s maker
  projects, finished work, experiments, and retrospectives.
- Original green-and-silver framing with a static CSS nebula/starfield and
  system fonts. Avoid copied franchise interfaces or unlicensed branding.
- Eleventy, Markdown/Nunjucks, npm, stable readable URLs, and individual bylines.
- Three approved initial Logs: website development, Pablo, and First Step Epoch.
- WCAG 2.2 AA as the target, with keyboard access, visible focus, meaningful
  image descriptions, responsive layouts, reduced motion, and readable CSS-off
  content. Use change-based review, not repeated guided article checklists.
- No required JavaScript for navigation or reading; optional illustrations have
  clear requirements and static/written alternatives.
- No analytics, advertising, tracking pixels, exposed contact details, or remote
  asset dependencies. Public names are first-name-only; use approved Git identity.
- Full-entry RSS, newest 20, first-name creators without email, canonical feed
  plus identical compatibility copies.
- Prefer less than 100,000 uncompressed bytes per page; hard ceiling 512,000.
  Keep optional-heavy pages separately linked and measure generated resources.
- Reusable software under MIT; retain separate content rights and third-party
  provenance/credits. Preserve the original 88-by-31 button and Elbow-star icons.
- Publish only reviewed source, writing, assets, and documentation. Keep private
  drafts/research and historic development out of this repository and Git history.
- Public source was explicitly approved November 13, 2026. Keep the historical
  repository private. GitHub Pages is the chosen first host; Cloudflare retains
  domain registration and DNS. Sam separately approved the first deployment and
  DNS cutover November 13, 2026. Future releases remain manually approved.
- Retain article completion dates through launch rather than resetting all entries
  to deployment day. Hosting and source publication are separate checkpoints.

## Local operation and public homelab learning goal

- Maintain a production build that can be generated and served without GitHub
  Actions or a hosting-provider API.
- Keep a working home-network/offline mirror of the published site.
- Eventually serve the public website from home as an explicit, substantive
  learning milestone. This is more than a backup or local-preview exercise.
- Preserve the domain, article URLs, RSS identity, and an independently restorable
  static build when changing hosts. See [hosting](hosting.md) for acceptance steps.
